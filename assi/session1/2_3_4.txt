2.supervised & Unsupervised diffrence
---------------------------------------

| Feature            | Supervised Learning                                                | Unsupervised Learning                            |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------------------ |
| Data               | Uses labeled data                                                  | Uses unlabeled data                              |
| Goal               | Predict output or class                                            | Discover hidden patterns or groups               |
| Output             | Classification or Regression                                       | Clustering or Association                        |
| Example App        | Instagram predicts which posts you'll like based on previous likes | Spotify groups similar songs to create playlists |
| Algorithm Examples | Linear Regression, Decision Tree, Random Forest                    | K-Means, DBSCAN, Hierarchical Clustering         |
| Real-world Example | Gmail spam detection, Flipkart product recommendation              | Customer segmentation, Movie/music grouping      |

4. Real-world Uses of Unsupervised Learning
--------------------------------------------

| Platform | Data Required                                        | Hidden Pattern / Insight                                                             |
| -------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Zomato   | Restaurant ratings, cuisine, location, order history | Group similar restaurants and identify customer preferences.                         |
| Flipkart | Purchase history, browsing behavior, cart items      | Segment customers into budget buyers, premium buyers, or frequent shoppers.          |
| Spotify  | Listening history, genres, artists, play count       | Group similar songs and users to create personalized playlists like Discover Weekly. |
